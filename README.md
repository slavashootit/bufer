# Bufer

Менеджер буфера обміну для macOS. Пам'ятає все, що ти копіюєш, і віддає це назад за **⌘⇧V**.

### [⬇︎ Скачати Bufer для Mac](https://github.com/slavashootit/bufer/releases/latest/download/Bufer.dmg) · [Сайт з демо](https://slavashootit.github.io/bufer/)

Або одною командою в Терміналі (ставить і оновлює, без попередження macOS):
```bash
curl -fsSL https://raw.githubusercontent.com/slavashootit/bufer/main/install.sh | bash
```

macOS 14 або новіша, Apple Silicon і Intel.

## Що вміє
- Історія тексту (разом із форматуванням), посилань, кольорів, картинок і файлів, з програмою-джерелом.
- **⌘⇧V натиснути й відпустити:** вікно біля курсора, клік по запису вставляє його туди, де курсор.
- **⌘⇧V затиснути:** перетягуй записи мишкою в будь-яке поле.
- Бокова панель: закріплені, типи, програми-джерела.
- Пошук за кількома словами, у тому числі по тексту на скриншотах.
- Вставка з форматуванням або простим текстом (⌥), кількох записів одразу (⇧клік).
- Перегляд на пробіл, правий клік — меню дій, **⌘⌥⇧V** вставляє останнє простим текстом.
- Не записує паролі з 1Password, Bitwarden, Keychain і Passwords; будь-яку програму можна виключити.
- Налаштування: свої гарячі клавіші, ліміт і автоочищення історії, можна сховати іконку з меню-бару.
- Усе зберігається лише на твоєму Маці, нікуди не відправляється.

## Встановлення
1. Скачай `Bufer.dmg`, відкрий і перетягни **Bufer** у теку **Applications**.
2. Запусти Bufer. macOS скаже, що не може перевірити розробника: програма не підписана платним
   сертифікатом Apple. Відкрий **System Settings → Privacy & Security**, прокрути вниз і натисни
   **Open Anyway** («Все одно відкрити»). Це потрібно лише один раз.

   Або одною командою в Терміналі:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Bufer.app && open /Applications/Bufer.app
   ```
3. Дозволь **Accessibility**, коли Bufer попросить (System Settings → Privacy & Security →
   Accessibility → увімкнути Bufer). Без цього клік по запису лише копіює, а ⌘V натискаєш сам.

Після оновлення до нової версії macOS може попросити дозвіл Accessibility ще раз: видали Bufer
зі списку кнопкою «−» і додай знову.

## Клавіші
| Клавіша | Дія |
|---|---|
| ⌘⇧V | відкрити історію (натиснути) / тримати й перетягувати (затиснути) |
| ⌘⌥⇧V | вставити останнє простим текстом, без вікна |
| клік / ↩ | вставити |
| ⌥клік / ⌥↩ | вставити простим текстом |
| ⇧клік, ⇧↑↓ | позначити кілька, ↩ вставляє всі |
| пробіл, ⌘Y | перегляд |
| ⇥ / ⇧⇥ | розділи бокової панелі |
| ⌘1…⌘9 | вставити 1–9-й запис |
| ⌘C · ⌘P · ⌘⌫ | скопіювати · закріпити · видалити |
| ⌘, | налаштування |
| Esc | закрити |

## Зібрати самому
Потрібні Command Line Tools (`xcode-select --install`).
```bash
./build.sh            # зібрати й встановити у /Applications для себе
scripts/package.sh    # універсальний Bufer.dmg у dist/
```

## Новий реліз
1. Підніми версію в `Info.plist` (`CFBundleShortVersionString`, наприклад `0.4`) і запуш.
2. GitHub → **Actions → Release → Run workflow**.

GitHub сам збере Bufer на своєму Маці й викладе `Bufer.dmg` у Releases. Посилання «Скачати»
вгорі завжди веде на останню версію. Можна й тегом: `git tag v0.4 && git push origin v0.4`.
